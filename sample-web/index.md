## Toyota mẫu đơn giản

<iframe id="livePreview" src="https://plna.github.io/toyotadongthap" width="100%" height="500px"></iframe>
<script>
  setInterval(function() {
    var iframe = document.getElementById('livePreview');
    if (iframe) {
      iframe.src = iframe.src;
    }
  }, 60000);
</script>
